\abstract{Recently, virtual assistant tools based on artificial intelligence, such as ChatGPT, gained much attention from the media and the general public. That raised questions about which kind of tasks the usage of such a tool can be applied. For agile software development, having a good code design is essential to keep it ready to change. In this context, identifying which design pattern can be appropriate for a given scenario can be considered an advanced skill that requires a high degree of abstraction and a good knowledge of object orientation. So, the goal of this paper is to perform an exploratory study investigating the effectiveness of ChatGPT in assisting developers in choosing a design pattern to solve design scenarios. To reach this goal, we gathered 50 existing questions used by teachers and public tenders that provide a concrete context and ask which design pattern would be suitable. These questions were submitted to ChatGPT, and the answers were analyzed. As a result, 96\% of the questions were answered correctly with a good level of detail, demonstrating the potential of such a tool as a valuable resource to help developers to apply design patterns and make design decisions.}

%\abstract{This study evaluates the effectiveness of ChatGPT, an AI-assisted tool capable of suggesting design patterns based on specific requirements or problems, in assisting developers in choosing a design pattern to solve a design scenario. The results indicate that ChatGPT got 96\% of the questions right and 4\% wrong, demonstrating its potential as a valuable resource to help developers recognize and interpret design patterns. The study highlights the importance of design patterns in software development and the efforts being made to educate and train developers in their use. Overall, this study is a promising step in the development of AI-assisted tools for software development.}

\section{Introduction}\label{sec1}

The use of design patterns\cite{bib1,bib3,bib6} in software development is a practice that brings several advantages, including code reuse, better code organization, ease of maintenance, better scalability, and software quality\cite{ bib4, bib8}. In the context of agile methods, these characteristics are essential to keep the code ready to change, enabling adjustments in requirements in small iterations. However, becoming proficient in understanding and applying these patterns can take time and effort\cite{bib2}, requiring a high degree of abstraction and practice in object-oriented programming. Educational institutions use various learning techniques\cite{bib5, bib7} to engage students with real-world problems in recognizing and interpreting these patterns.

ChatGPT is an AI-assisted tool capable of answering questions in a conversational way. Recently, this kind of tool has been receiving a lot of attention from the media and the general public, raising questions about the potential of its application in several fields, such as public health \cite{biswas2023role} and academia \cite{lund2023chatting}. Some recent works suggest its use for software engineering applications, such as solving programming bugs \cite{surameery2023use} and improving other kinds of activities, like requirements engineering and code quality \cite{white2023chatgpt}.

The goal of this paper is to investigate if an AI-assisted tool can help developers to make design decisions, like suggesting appropriate design patterns to apply in a given scenario. To reach that goal, we performed an exploratory study considering 50 exercises and exam questions obtained from educational institutions and public tenders, which present a concrete context and ask which pattern should be applied. We used ChatGPT for this study, and we evaluated how many answers it answered correctly based on the question official answer, and what elements that can help in the pattern implementation are present in the answers. For wrong answers, we also assessed if they could mislead the developer to a wrong path.

As a result, the AI-assisted tool was able to answer correctly 94\% of the questions, providing answers that mention specific details of the scenario, providing guidance to the pattern implementation mentioning which classes and interfaces should be created. \textbf{Related to the wrong answers...} Based on that, we consider the results of this initial assessment promissing, pointing a potential of such tools to assist on software design decisions.

\section{Research Design}\label{sec4}

Based on the goal of investigating if an AI-assisted tool can help developers in choosing the appropriate design pattern to apply in a given scenario, we formulated three more specific research questions:

\begin{enumerate}
    \item $RQ_1$ - How is the success rate of the AI-assisted tool in suggesting design patterns?
    \item $RQ_2$ - Does elements provided in the answer of the AI-assisted tool help in the pattern implementation?
    \item $RQ_3$ - In questions where the wrong pattern is pointed, does the AI-assisted tool answer mislead the developers?
\end{enumerate}

To answer these research questions, we collected preexisting questions prepared by higher education professors or public tenders in which a scenario is described and it asks which design pattern should be applied. We choose ChatGPT as the AI-assisted tool to be used in the study and we submitted the selected questions to it, registering the answers. The content of the answers were analysed, not only comparing to the exercise correct answer ($RQ_1$), but also analyzing what elements that can help the developers in the pattern implementation were present ($RQ_2$). A qualitative analysis was done in the wrong answers to evaluate if they can mislead the developers ($RQ_3$).

To select the answers, we contacted professors that teach design patterns in universities asking for exam questions and exercises that they give to students. We've received the material from three professors from different countries: Italy, United States, and Portugal. We also analysed available exams of public tenders for 26 Brazilian institutions. As a question inclusion criteria for this study, we considered the following criteria: (a) the solution should be one of the “Gang of Four” (GoF) patterns; (b) the question should describe a scenario and ask which pattern should be applied; and (c) the question should describe a concrete scenario and not just give general requirements. 

The first criteria was to restrict the scope of the study to these patterns, which are well know by the software development community and taught in university courses. That criteria enabled finding a good number of questions. The two other criteria were considered to choose questions that better simulate the decision of a applying a pattern in a real scenario.
